# Custom firmware 0.6.3

| File | Purpose |
| --- | --- |
| `custom-0.6.3-pickit.hex` | Full PICkit image for a fresh install or recovery. |
| `custom-0.6.3-from-oem.hex` | OEM updater image for converting stock OEM firmware to custom. Serve it as `firmware.hex` from the Docker update server. |
| `custom-0.6.3-update.efu` | OTA package for a device already running custom firmware. |
| `custom-0.6.3.bin` | Raw PIC image for inspection; use the HEX or EFU file for installation. |
